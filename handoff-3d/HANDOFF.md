# Передача: 3D-моделирование для Living Factions (от Cowork к локальной сессии)

Цель: локальная сессия Claude Code продолжает делать 3D-модели предметов для мода Living Factions (Valheim, BepInEx, Jötunn) в стиле игры: низкополигональные меши, пиксельные текстуры, без CDN и внешних библиотек в движке.

## Что внутри
- `lowpoly-kit/` — собственный WebGL2-движок (`engine/lowpoly.js`, глобал `LP`), модели (`models/*.js`), помощники `LPK` (_common), `LPB` (_blade), `LPG` (_glow), инструменты сборки (`tools/`), `render.html`, готовые рендеры (`output/`). Читай `CLAUDE.md`, `README.md` и `START_HERE.md` первыми.
- `boards/` — доски-превью канваса (`.dc.html`) и `canvas.json`. Версия на всех досках: v0.4.0 (текущая версия мода). Доска Banner 960×240 и Avatar 512×512 — в стиле превью.

## Методика (кратко)
1. Форма строится из `LP.Scene`: `mesh`, `extrude`, `prism`, `box`, `lathe`, `tube`, `ribbon`. Для лезвий — `LPB.blade`.
2. Свечение: `LPG.accents(sc, rnd, {X,Y,S}, {name, color, spines, bz, br, grip, gr, gem, gz, gs})` добавляет светящиеся трубки по лезвию, полосу на рукояти (если `grip` не null) и светящийся октаэдр-гем фракции. Светящиеся меши — пятым аргументом `emit=1`. Глоу-проход: `tools/postprocess.py --glow`.
3. Детерминизм: порядок вызовов `rnd` важен. Новые элементы добавляй в конец `build()`. Новые текстуры — через `LP.canvasTex` с фиксированным цветом, без `rnd`.
4. Сборка одной модели: `bash tools/build_all.sh <id>` → `output/<id>.png`, `output/<id>-icon.png`, `output/export/`. Проверки — PIL `getbbox` и контактные листы.

## Правила
- Файлы мода (`E:\valheim-living-factions`, `src/`, `dist/`, `docs/`) не менять без согласования с пользователем. Работать только в `lowpoly-kit/`.
- Всё, что уходит назад в Cowork-канвас или в мод, сначала согласовывать с пользователем.
- Версию мода брать из `src/LivingFactions/LivingFactions.csproj` (сейчас 0.4.0), не из старых досок.
- Фракционные топоры: 7 штук (Клык Волка, Воронье Крыло, Рог Оленя, Черногрыз, Рунная Двусечка, Корнеруб, Курганная Луна). Щиты и мечи — по 7, луки — не сделаны.
