# Thunderstore

Загрузка: https://thunderstore.io/c/valheim/create/ → выбрать команду `under2ker` → перетащить
`dist/LivingFactions-0.6.5.zip`.

Страница мода на Thunderstore: это README.md из архива, описание короткое: из `manifest.json`.
Оба уже в архиве, вставлять руками ничего не нужно.

## Категории (отметить в форме)

- Mods
- AI Generated (обязательно по правилам сайта)
- Client-side
- Server-side
- Gameplay (если есть в списке)
- Gear
- NPCs (если есть в списке)

## Что стоит в manifest.json

```
NPC factions build settlements, fell and replant forests, trade and go to war. Boss hunts, relic axes and swords, multiplayer. EN, RU, PL, DE, FR, ES, PT. Discord: discord.gg/qVfAq3fqj6
```

Зависимости: `denikson-BepInExPack_Valheim-5.4.2351`, `ValheimModding-Jotunn-2.30.2`.

## Проверить после загрузки

- Номер версии на странице: 0.6.5.
- Иконка с v0.6.5 (старые версии на сайте остаются со своими иконками, это нормально).
- В README видны обложка, таблицы топоров и мечей, обе картинки с оружием и галерея снимков.
