# Thunderstore

Загрузка: https://thunderstore.io/c/valheim/create/ → выбрать команду `under2ker` → перетащить
`dist/LivingFactions-0.7.0.zip`.

Страница мода на Thunderstore: это README.md из архива, описание короткое: из `manifest.json`.
Оба уже в архиве, вставлять руками ничего не нужно.

## Категории (отметить в форме)

- Mods
- AI Generated (обязательно по правилам сайта)
- Client-side
- Server-side
- Gameplay (если есть в списке)
- Gear
- NPCs (если есть в списке)

## Что стоит в manifest.json

```
NPC factions build settlements, trade, fell and replant forests, march war bands and lay siege. Envoys, boss hunts, relic axes, swords and shields, multiplayer. EN, RU, PL, DE, FR, ES, PT. Discord: discord.gg/qVfAq3fqj6
```

Зависимости: `denikson-BepInExPack_Valheim-5.4.2351`, `ValheimModding-Jotunn-2.30.2`.

## Проверить после загрузки

- Номер версии на странице: 0.7.0.
- Иконка с v0.7.0 (старые версии на сайте остаются со своими иконками, это нормально).
- В README видны обложка, таблицы топоров, мечей и щитов, все три картинки с оружием (топоры, мечи, щиты) и галерея снимков.
